## 0. 큰 그림 — "정상을 배우고, 벗어난 걸 찾는다"
지도학습은 "이건 공격, 저건 정상"을 **정답 주고** 가르친다. 그런데 **처음 보는 공격**은 정답에 없어서 못 잡는다.
비지도 이상탐지는 반대다: **"평소(정상)가 어떤 모양인지"만 배우고, 그 모양에서 멀리 벗어난 걸 "이상"이라** 한다.
정답(라벨)이 없어도 되니, **룰에도 없고 본 적도 없는 공격**을 잡을 수 있다. 이게 우리가 비지도를 쓰는 이유.

핵심 질문 하나: **"벗어났다"를 어떻게 잴까?** 재는 방법이 달라서 모델이 나뉜다.

---

## 1. Isolation Forest (IF) — "이상한 점은 빨리 외톨이가 된다"

**직관:** 점들을 **무작위 선으로 계속 자른다**. 한 점만 남을 때까지. 이상치는 주변에 친구가 적어서 **몇 번 안 잘라도 혼자 뚝 떨어진다**. 정상은 빽빽해서 여러 번 잘라야 겨우 떼어진다.
→ **"혼자가 되기까지 자른 횟수(깊이)"가 작으면 = 이상.**

**비유:** 사람 많은 방에서 "반으로 나누기"를 반복해 한 명만 남기기. 구석에 혼자 있던 사람은 2~3번이면 분리됨(=이상). 가운데 뭉쳐 있으면 10번 넘게 걸림(=정상).

**강점:** 빠르고, 전체에서 **확 튀는** 공격(예: 분당 요청 폭증)에 강함.
**약점:** **느린 공격**은 값이 전역적으로 크게 안 튀어서 깊이 안 깊어짐 → **놓침.**
**우리 결과:** 느린 BOLA를 IF가 놓침(정본 탐지 0.47~0.59). = H5의 "IF가 놓친다" 쪽.

## 2. LOF (Local Outlier Factor) — "내 주변만 보고 판단"

**직관:** IF는 전체를 보지만, LOF는 **내 바로 옆 이웃(k명)과 나의 밀도만** 비교한다. 이웃들은 서로 빽빽한데 **나만 듬성하면 = 국소 이상.**
→ 전역적으론 안 튀어도, **자기 동네에서 혼자 이상하면** 잡는다.

**비유:** 동네마다 집 간격이 다르다. 아파트 단지(빽빽)에 혼자 마당 넓은 집이 있으면, "전국 평균"으론 정상이어도 **그 동네 기준으론 이상**. LOF는 이 "동네 기준"을 본다.

**강점:** **느린·국소** 공격을 IF보다 잘 잡음.
**약점:** 거리·밀도 계산이라 **스케일링 필수**(피처 크기 안 맞추면 큰 숫자가 지배).
**우리 결과:** IF가 놓친 느린 BOLA를 **LOF가 잡음**(정본 0.81~0.88). = H5의 "LOF가 보완" 쪽. **실제 운영 후보.**

## 3. Autoencoder (AE) — "정상을 따라 그리게 시키고, 못 그리면 이상"

**직관:** 입력을 **작게 압축했다가 다시 복원**하는 신경망을, **정상 데이터로만** 연습시킨다. 정상은 많이 봤으니 잘 복원한다(원본≈복원). 처음 보는 이상은 **복원이 어긋난다** → **원본과 복원의 차이(재구성 오차)**가 크면 이상.

**비유:** 평소 얼굴만 수천 번 그려본 화가. 아는 얼굴은 척척 그리는데, 처음 보는 얼굴은 어설프게 그림 → "어설픔의 정도"로 낯섦을 잰다.

**강점:** 복잡한 정상 패턴도 학습.
**약점:** **정상이 대표성 있어야** 함. 학습 때 본 정상과 실제 정상이 다르면(분포 shift) 정상도 "못 그려서" 오탐↑.
**우리 결과:** 두 종류 정상 섞으니 오탐 0.88 폭증 → **두꺼운 정상** 주니 0.00으로 붕괴(§L). AE는 정상 품질에 제일 예민.

> **회귀 연결:** AE는 "입력을 예측(복원)"하니 회귀의 일종. "정상을 예측 → 벗어나면 경보"가 핵심(`docs/19` 회귀 설명).

## 4. contamination — 하나뿐인 중요한 노브
세 모델 공통 설정. **"데이터의 몇 %를 이상으로 볼까"**의 임계값.
- 0.1 = "상위 10%를 이상으로" → 공격 없어도 10% 경보(오탐↑).
- 낮추면(0.01) 오탐↓ 하지만 아슬한 공격도 놓칠 수 있음.
- **정상 데이터로 정하고, 채점 보며 조정 안 함**(그러면 반칙). 우리 스윕: §D.

## 5. 왜 셋을 같이 쓰나 (앙상블)
- IF: 확 튀는 공격 / LOF: 국소·느린 / AE: 복잡한 패턴. **각자 놓치는 걸 서로 메운다.**
- 우리 `IF|LOF|AE`(하나라도 이상이면 경보): 정본 **0.91~0.97 탐지 / 오탐 0.00~0.02.**
- 이게 "2층 모델"의 **발견(discovery)** 층. 그 위에 RF가 **종류 이름**을 붙인다(분류).

## 6. 직접 해보기 (감 붙이기)
```bash
# contamination 바꿔 오탐이 어떻게 변하나 (낮출수록 오탐↓)
python ml/supervised.py datasets/real_web/real_canon_features.csv \
  --answer datasets/real_web/real_canon_answer.csv --group-by type --contamination 0.03
# 피처 하나 빼면 탐지가 어떻게 변하나 (그 피처의 역할 체감)
python ml/supervised.py datasets/real_web/real_canon_features.csv \
  --answer datasets/real_web/real_canon_answer.csv --group-by type --drop endpoint_entropy
```
→ 숫자가 어떻게 움직이는지 보는 게 책 열 줄보다 빨리 와닿는다.

## 한 문장 정리
> **정상을 배우고 벗어남을 잰다. IF=전역 외톨이, LOF=동네 밀도, AE=복원 오차. 느린 공격은 LOF/AE가,
> 빠른 건 IF가 — 그래서 같이 쓴다. contamination으로 민감도, 스케일링·대표성 정상이 품질을 좌우.**
