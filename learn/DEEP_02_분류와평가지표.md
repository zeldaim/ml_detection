# 깊이 이해 02 — 분류(RandomForest)와 평가지표

> 원저작 설명(책 발췌 아님) + 우리 숫자. 앞: `DEEP_01_이상탐지.md`. 용어: `GLOSSARY.md`.

## 0. 분류 vs 이상탐지 — 역할이 다르다
- **이상탐지(DEEP_01)**: "평소와 다른가?" → 발견. 라벨 없이, **처음 보는 공격**도.
- **분류(여기)**: "이게 **무슨** 공격인가?" → 이름 붙이기. 라벨 필요, **아는 공격만**.
- 우리 2층: 비지도가 **발견**, RandomForest가 **종류 분류**. (`classify_type.py`)

## 1. 결정 트리 — 분류의 부품
**직관:** 스무고개. "분당요청 100 넘어? → 예: 에러율 0.9 넘어? → 예: 대입공격". 조건으로 가지를 쳐서 잎(답)에 도달.
- **분기(split)**: 어떤 피처·값에서 나눌지. "가장 깔끔하게 둘로 가르는" 지점 선택(지니 불순도↓).
- 약점: 트리 하나는 **과적합**(학습 데이터에 너무 맞음) 쉬움.

## 2. RandomForest — "트리 여러 개의 투표"
**직관:** 트리 하나는 편향될 수 있으니, **데이터·피처를 조금씩 다르게** 해서 트리 수백 개를 키우고 **다수결**.
- **배깅**: 각 트리는 전체에서 **무작위 재추출**한 샘플로 학습 → 서로 다른 관점.
- **피처 무작위**: 각 분기에서 피처 일부만 후보 → 트리들이 다양해짐.
- **효과**: 한 트리의 실수를 다른 트리가 상쇄 → 과적합↓, 안정↑.
**비유:** 한 명의 전문가(편향 위험)보다 **다양한 배경의 여러 명 투표**가 더 믿을 만하다.

**피처 중요도:** RF는 "어느 피처로 주로 갈랐나"를 알려줌 → 쓸모없는 피처 제거 근거.
**우리 결과:** RF 중요도 상위 `err_ratio`·`endpoint_entropy`·`uniq_objects`. 공격을 가르는 핵심 피처가 뭔지 보임.

**한계(중요):** RF는 **학습에 있던 종류만** 분류. 처음 보는 공격은 → 비지도가 발견해야. (우리 E2: RF 처음보는공격 0.29)

## 3. 평가지표 — "정확도"만 보면 속는다
공격이 드물면(예: 정상 95%) "전부 정상"이라 찍어도 **정확도 95%**. 그래서 정확도는 위험. 대신:

**혼동행렬(confusion matrix):**
| | 실제 공격 | 실제 정상 |
|---|---|---|
| 공격이라 판정 | TP(맞음) | FP(오탐) |
| 정상이라 판정 | FN(놓침) | TN(맞음) |

- **정밀도(Precision) = TP/(TP+FP)**: "공격이라 한 것 중 진짜 비율". 높으면 **헛경보 적음**.
- **재현율(Recall) = TP/(TP+FN)**: "진짜 공격 중 잡은 비율". 높으면 **놓침 적음**. (= 우리 "탐지율")
- **F1 = 둘의 조화평균**: 정밀도·재현율 균형.

**보안에서의 트레이드오프:**
- 재현율↑(다 잡기) 하려면 임계값 낮춤 → **오탐↑**(피곤).
- 정밀도↑(헛경보 줄이기) 하려면 임계값 높임 → **놓침↑**(위험).
- 그래서 우리는 **탐지율과 오탐률을 '같이'** 본다(둘 중 하나만 보면 속음, `docs/17`).

**우리 숫자 예(정본, IF|LOF|AE):** 탐지율 0.97 / 오탐률 0.00 → 거의 다 잡고 헛경보 없음(이 랩 기준).

## 4. 올바른 평가 — 안 본 데이터로
- **학습/시험 분리**: 같은 데이터로 학습·평가하면 "외운 걸 맞히는" 거라 의미 없음(과적합 숨김).
- **교차검증**: 데이터를 나눠 번갈아 평가.
- **leave-one-group-out(우리)**: 공격 **종류를 통째로 빼고** 학습 → "**처음 보는** 종류"를 잡나(E2). 가장 엄격. (`supervised.py`)
- **퍼뮤테이션 검사**: 라벨 섞어 성능이 바닥나면 "진짜 학습", 그대로 높으면 "누수/고장". (`verification/`)

## 5. 직접 해보기
```bash
# RF 종류 분류 — 혼동행렬·종류 정확도
python ml/classify_type.py datasets/real_web/real_canon_features.csv --answer datasets/real_web/real_canon_answer.csv
# 처음 보는 공격(E2) — 종류 빼고 학습
python ml/supervised.py datasets/real_web/real_canon_features.csv --answer datasets/real_web/real_canon_answer.csv --group-by type
```

## 한 문장 정리
> **분류=이름붙이기(아는 공격), RF=트리들의 투표(과적합↓). 정확도 대신 정밀도·재현율·F1을 같이 보고,
> 안 본 데이터(leave-one-group-out)로 평가해야 속지 않는다. 처음 보는 공격은 분류가 아니라 이상탐지의 몫.**
