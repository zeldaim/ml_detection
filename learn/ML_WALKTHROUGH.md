## A. 알고리즘 — 어떻게 '동작'하나 (우리 결과로)

### A1. Isolation Forest (IF) — "이상치는 빨리 고립된다"
- **원리**: 데이터를 **무작위로 반복 분할**한다. 이상치는 주변에 점이 적어 **몇 번 안 잘라도 혼자 떨어진다**(짧은 경로). 정상은 밀집해 많이 잘라야 분리됨 → **분리까지의 깊이**가 이상 점수.
- **노브**: `contamination`(데이터의 몇 %를 이상으로 볼지 = 임계).
- **우리 결과**: 느린 공격(bola_slow)을 **놓침**(실험 F·L, 탐지 0.59). 왜? 느린 공격은 전체 분포에서 "값이 크게" 안 튀어서 전역적으로 잘 안 고립됨.
- **쓸 때/피할 때**: 전역적으로 동떨어진 공격엔 빠르고 좋음. **국소적·느린 공격엔 약함** → LOF로 보완.

### A2. LOF (Local Outlier Factor) — "이웃보다 밀도 낮으면 이상"
- **원리**: 각 점의 **국소 밀도**를 이웃(k개)과 비교. 내 밀도가 이웃보다 많이 낮으면 이상. **전역이 아니라 "주변 대비"**를 봄.
- **노브**: `n_neighbors`(이웃 수), `contamination`.
- **우리 결과**: 느린 공격을 **잡음**(실험 L, 탐지 0.88, H5에서 IF가 놓친 9구간 보완). 국소 비교라 "주변 정상과 조금 다른" 느린 이상도 포착.
- **쓸 때/피할 때**: 국소 이상·느린 공격에 강함. 밀도 기반이라 **스케일링 필수**(거리 계산). 우리 실제에서 **운영 후보**.

### A3. Autoencoder (AE) — "정상을 복원하게 학습, 복원 못 하면 이상"
- **원리**: 입력을 **압축했다 복원**하는 신경망을 **정상으로만** 학습. 정상은 잘 복원(오차 작음), 처음 보는 이상은 복원 실패(오차 큼) → **복원오차**가 점수. **회귀의 일종**.
- **노브**: 구조(은닉 크기), `contamination`(오차 임계).
- **우리 결과**: 탐지 좋지만(0.88~1.00) **분포 shift에 민감** — 서로 다른 정상 분포를 섞으면 오탐 폭증(0.88), **대표성 있는 정상**을 주면 붕괴(0.00, 실험 H·L). = "정상을 제대로 배워야" 동작.
- **쓸 때/피할 때**: 복잡한 정상 패턴에 강하지만 **정상 데이터 품질·대표성에 가장 예민**.

### A4. Random Forest (RF) — "트리 여러 개의 투표" (지도/분류)
- **원리**: 조건 분기 트리를 **데이터·피처를 랜덤히 바꿔** 여러 개 학습 → 다수결. 라벨이 필요한 **지도학습**.
- **노브**: 트리 수, 깊이.
- **우리 결과**: **학습에 있던 공격은 잘 분류, 처음 보는 종류는 못 잡음**(E2: 0.29). 피처 중요도로 "어느 피처를 썼나"도 봄(err_ratio·엔트로피 상위).
- **쓸 때/피할 때**: 아는 공격 **종류 이름 붙이기**에 좋음. **발견(처음 보는 것)은 비지도 몫.**

> **그래서 2층**: 발견=비지도(IF·LOF·AE), 분류=지도(RF). 편향 위험을 지도 쪽에 가둠(`docs/19` §6-1).

## B. 피처 엔지니어링 — 가장 큰 지렛대 (판다스 아님, 판단)

피처 = 모델에게 던지는 질문. **같은 알고리즘도 피처가 없으면 그 공격을 못 본다.**

| 피처 | 아이디어 | 어느 공격 | 교훈 |
|---|---|---|---|
| `max_req_1min` | 분당 피크 | 대입·고속 | 속도 축 |
| `uniq_objects` | 소유자원 객체 수 | BOLA | 내용 축 |
| `endpoint_entropy` | 경로 분포 다양성 | 스캐너 vs 정상 | **속도 겹칠 때 내용으로 가름**(실험 J) |
| `반복도`(q/템플릿) | DB 쿼리 반복 | DB scrape | **파생 피처가 raw보다 나음**(DB §) |
| `rel_*`(상대값) | 평소 대비 배수 | 탈취 급증 | **UEBA**: 절대 못 가르는 걸 상대로(실험 K) |

**철칙 (실험 E vs J에서 굳힘):**
1. 피처는 **제안(사람/LLM) → 교차검증 통과해야 채택.** seq_id_score는 데이터가 **거부**(중복), entropy·반복도·상대값은 **채택**.
2. **한 번에 하나씩** 추가하고 효과 확인. 쓸모없으면 뺀다(단순할수록 안정).
3. **파생 피처**(비율·상대값)가 raw보다 나은 경우가 많다(반복도·rel).

## C. 전처리 판단 — 모델 품질을 좌우하는 결정들

가공(판다스)이 아니라 **판단**. 이게 전처리의 핵심이고 책보다 우리 사례가 명확하다.

| 결정 | 뭐·왜 | 우리 코드/실험 |
|---|---|---|
| **스케일링** | 피처 크기 맞춰 거리·밀도 모델이 공평히 보게 | `StandardScaler`(LOF·AE 전). 안 하면 큰 숫자 피처가 지배 |
| **누수 방지** | 라벨을 몰래 포함한 피처 금지(가짜 완벽) | IP·UA·pod이름 **피처로 안 씀**. 공격 표식도 라벨에만 |
| **학습/평가 분리** | 평가셋에 맞춰 튜닝 금지 | `--train-until`(정상 기간만 fit), `leave-one-group-out`(처음 보는 공격), held-out |
| **불균형** | 정상 많고 공격 적음 | 비지도는 **정상만 학습**(공격 불필요), `contamination`으로 임계. 공격은 종류·변주가 중요 |
| **정상 대표성** | 정상이 현실적·다양해야 | 두꺼운 정상 → AE 오탐 0.88→0.00(실험 L). **정상 생성기 속도 왜곡 주의**(실험 I) |

## D. 꼭 아는 핵심 개념 (우리가 숫자로 체험한 것)

- **편향 vs 분산**: 양은 분산↓, **다양성은 편향↓**(다른 약). `docs/19` §6-1, AE 분포shift가 편향 실례.
- **과적합/일반화**: 한 도구·환경에 맞춰지면 새 것에 실패. 행위 피처·다양한 출처로 완화.
- **분포 shift**: 학습≠평가 분포 → 성능 하락(AE 오탐). 대표성으로 대응.
- **하드 네거티브**: 공격과 닮은 정상을 일부러 넣어 진짜 경계를 배우게(fastclient, 실험 J).
- **퍼뮤테이션 검사**: 라벨 섞어 "모델이 진짜 신호 배우나 vs 고장" 확인(가짜 0% 나와야 정상).
- **임계(contamination)**: 낮추면 오탐↓(탐지도 조심). 스윕으로 곡선 봄(실험 D).

## E. 이 프로젝트로 계속 배우는 법

1. **파라미터 바꿔 보기**: `supervised.py --contamination 0.03` / `--drop endpoint_entropy` → 숫자 변화 관찰 = 알고리즘 감.
2. **코드 읽기**: `ml/models.py`(각 모델 몇 줄), `ml/supervised.py`(교차검증), `ml/features.py`(피처 계산).
3. **레퍼런스**: scikit-learn User Guide의 IsolationForest/LOF/RandomForest 페이지(짧고 정확).
4. **실험 재현**: `docs/21`의 실험 하나 골라 다시 돌려 보기.

> 요약: **알고리즘은 원리 1문단 + 우리 결과로, 피처·전처리는 "판단"으로, 책 대신 레퍼런스+실험.** 판다스는 범용 가공용으로만.
