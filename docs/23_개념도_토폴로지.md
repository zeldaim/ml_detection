## 2. 출발지 IP 역할 맵 — 로그의 "출발지"가 곧 라벨 키

```mermaid
flowchart TB
  subgraph N["정상 (normal)"]
    n1["10.16.1.101~106\n사람 속도 사용자 6프로필"]
  end
  subgraph A["공격 (attack)"]
    a1["10.16.1.211~214\n1차: brute_fast·bola"]
    a2["10.16.1.221~227\n2차: 7종 동시"]
  end
  subgraph H["하드 네거티브 (정상이지만 어려움)"]
    h1["10.16.1.131~132\n빠른 합법 클라이언트"]
  end

```
> 라벨은 **출발지+시각 교집합**으로만. IP·UA 는 라벨 키일 뿐 **피처로는 안 씀**(누수 방지).

## 4. 플라이휠 — 데이터를 쌓아 모델을 키운다

```mermaid
flowchart LR
  C1["실제 로그 수집"] --> C2["라벨링(사실 기록)"]
  C2 --> C3[("누적 데이터셋")]
  C3 --> C4["재학습 train_export"]
  C4 --> C5["저장 모델 .joblib\n(버전 전부 보존)"]
  C5 --> C6["탐지 predict"]
  C6 --> C7["결과 검토"]
  C7 -->|"새 라벨"| C2
  C3 --> C8["검증 supervised\n교차검증"]
  C8 -->|"피처/파라미터 조정"| C4
```
> 탐지≠학습. 향상은 "같은 걸 반복"이 아니라 **데이터를 쌓아 재학습**. `fit`은 덮어쓴다(`docs/19` §1).

## 5. 2층 모델 — 발견(비지도) + 분류(지도)

```mermaid
flowchart TB
  IN["피처 (IP×5분)"] --> U
  subgraph U["비지도 = 발견 (라벨 없이 '평소와 다름')"]
    IF["IsolationForest\n전체서 동떨어짐\n느린 공격 놓침"]
    LOF["LOF\n국소 밀도\n느린 공격 잡음"]
    AE["Autoencoder\n복원오차\n분포 shift 민감"]
  end
  U --> OUT["이상 구간"]
  OUT --> S["지도 = 분류 (RandomForest)\n이상에 공격 이름 붙이기\n학습에 없던 종류는 못 잡음"]
  S --> R["🚨 이상 + 공격 종류"]
```
> 편향 위험을 **지도 쪽에 가둠**: 발견은 비지도(처음 보는 공격도)·이름만 지도(`docs/19` §6-1).

## 6. 실험 계보 A~I — 어떻게 쌓였나

```mermaid
flowchart TB
  A["A. 합성 2종\nH5 재현"] --> B["B. 합성 10종\n정상 현실화→오탐 드러남"]
  B --> D["D. contamination 스윕\n오탐↓ (버전 4종 저장)"]
  B --> Eexp["E. seq_id_score\n데이터가 거부→보류"]
  D --> F["F. 실제 로그\nH5 실제 재현"]
  F --> G["G. 실제 9종\nLOF>IF, AE 분포shift"]
  G --> Hh["H. 정상 보강\nAE↓ 그러나 겹침 드러남"]
  Hh --> I["I. 현실적 정상\n겹침은 대부분 인위적"]
  I --> J["J. 하드네거티브 fastclient\n(#2: endpoint_entropy 검증) — 진행중"]

```
