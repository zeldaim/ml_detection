# 쇼핑몰 사용 실험 참여 안내

보안 탐지 모델을 연구하고 있습니다. **평소 사람이 쇼핑몰을 어떻게 쓰는지** 기록이 필요해서 부탁드립니다.

## 하는 일 (20~30분, 가능하면 다른 날 한 번 더)

1. 받은 주소로 접속 → 브라우저 로그인 창에 **받은 아이디·비밀번호** 입력
   - PC·휴대폰 둘 다 됩니다. 어느 쪽으로 했는지만 알려주세요.
   - **휴대폰이면 카카오톡 등에서 링크를 바로 누르지 말고, 길게 눌러 Chrome 이나 Safari 로 열어 주세요.** (앱 안 브라우저에서는 로그인 창이 이상하게 뜰 수 있습니다)
2. 평소 인터넷 쇼핑하듯이 자유롭게 써 주세요. 예를 들면:
   - "친구 선물을 하나 골라 본다"
   - 둘러보다가 사고 싶은 게 없으면 그냥 나가도 됩니다
3. 회원가입·장바구니·결제는 **하고 싶으면** 하세요. 꼭 안 해도 됩니다.
4. 끝나면 시작·끝 시각만 알려주세요.

## 꼭 지켜 주세요

- **진짜 개인정보를 넣지 마세요.** 가입 이메일은 아무거나(예: `test123@test.com`), 주소·카드번호도 아무 숫자나 쓰시면 됩니다. 실제 결제는 일어나지 않습니다.
- 사이트가 보안 실습용이라 이상한 화면이 나올 수 있습니다. 신경 쓰지 말고 그냥 쓰시면 됩니다.
- 일부러 해킹을 시도하지는 말아 주세요. (정상 사용 기록을 모으는 실험입니다)

## 기록되는 것

- 기록됨: 받은 아이디(p01 같은 번호), 누른 페이지 주소와 시각, 브라우저 종류
- **기록 안 됨: 실제 IP 주소, 이름**
- 기록은 연구에만 쓰고, 공개할 때는 번호로만 남습니다. 원하시면 언제든 삭제해 드립니다.
